# Suggested GitHub Issues

Use these as execution tasks. Do not close an issue until the evidence or artifact actually exists.

## Discovery
- [ ] Recruit fleet owners / operations heads in the target segment.
- [ ] Recruit depot managers / dispatchers who prepare vehicles for shifts.
- [ ] Recruit drivers / riders who experience dispatch delays.
- [ ] Conduct and document discovery interviews with consent.
- [ ] Synthesize workflows, incidents, workarounds, frequency, and consequences.
- [ ] Search deliberately for counter-evidence and disconfirming cases.

## Market and strategy
- [ ] Verify competitor capabilities from current primary sources.
- [ ] Record source URLs, access dates, and exact claim supported.
- [ ] Compare target segments and buying processes.
- [ ] Reassess product wedge after discovery.
- [ ] Test willingness-to-pay and procurement assumptions without leading questions.

## Product definition
- [ ] Define operational readiness states and stale/unknown-data behaviour.
- [ ] Confirm the minimum user workflow worth prototyping.
- [ ] Write testable acceptance criteria for P0 requirements.
- [ ] Review permissions, auditability, privacy, and data retention requirements.
- [ ] Define metric instrumentation and denominator rules.

## Prototype and validation
- [ ] Create low-fidelity operator workflow.
- [ ] Create driver check-in and exception-reporting flow only if discovery supports it.
- [ ] Test core tasks with relevant users.
- [ ] Record task completion, errors, assistance, qualitative feedback, and limitations.
- [ ] Update requirements and document what changed.

## Portfolio quality
- [ ] Add dated evidence register.
- [ ] Replace provisional personas with evidence-backed profiles.
- [ ] Add screenshots or prototype link with clear prototype status.
- [ ] Prepare a concise case-study walkthrough with decisions and trade-offs.
